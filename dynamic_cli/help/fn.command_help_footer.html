pub(crate) fn command_help_footer(lead: &str, invocation: &str) -> String
Expand description

Footer an interface appends after the application help, telling how to get the help of one command, e.g. Type ':help <command>' for more information on a command.

lead is the verb phrase ("Type", "Run with") and invocation what the user enters (":help <command>", "--help <command>"). Shared by both interfaces so the line keeps a single style.
